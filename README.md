# Arcilla Arts

Arcilla Arts is a handmade jewellery e-commerce website, built with React, Vite, Framer Motion, and more.

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Deployment
This project is configured to be automatically deployed to GitHub Pages via GitHub Actions when pushing to the `main` branch.
